Docker安装caddy

约 502 字大约 2 分钟

dockercaddy

2025-01-15

注意

以下操作都在Ubuntu环境下进行，也可在其他Linux系统下操作，但如果出现问题请自行解决。

注意

使用non-root用户启动容器，默认当前用户，如有需要请自行更改

docker工作目录树

  • docker
    • caddy
      • Caddyfile
      • Dockerfile
    • compose.yaml
    • .env

新建docker工作目录

mkdir -p docker && cd docker

创建Dockerfile用来自定义构建容器

  1. 新建caddy目录
mkdir -p caddy && cd caddy
  1. 目录下新建配置文件Caddyfile

提示

vim Caddyfile
点我查看Caddyfile配置
# The Caddyfile is an easy way to configure your Caddy web server.
#
# Unless the file starts with a global options block, the first
# uncommented line is always the address of your site.
#
# To use your own domain name (with automatic HTTPS), first make
# sure your domain's A/AAAA DNS records are properly pointed to
# this machine's public IP, then replace ":80" below with your
# domain name.

localhost {
  # Set this path to your site's directory.
  root * /usr/share/caddy

  # Enable the static file server.
  file_server

  # Another common task is to set up a reverse proxy:
  # reverse_proxy localhost:8080

  # Or serve a PHP site through php-fpm:
  # php_fastcgi localhost:9000
}

import /etc/caddy/sites/*.conf
# Refer to the Caddy docs for more information:
# https://caddyserver.com/docs/caddyfile

提示

配置文件是从caddy容器内拷贝出来的，如有需要可自行修改

  1. 创建Dockerfile文件
FROM caddy:2.8.4-alpine

创建docker compose配置文件 compose.yaml

注意

  • 数据卷都挂载在 ${HOME}/data/caddy 目录下，请提前创建好对应目录，也可自行修改挂载目录
  • Caddyfile 配置文件需要拷贝到 ${HOME}/data/caddy 目录下
mkdir -p $HOME/data/caddy/{data,config,srv,sites}
services:
  caddy:
  build:
    context: caddy
    dockerfile: Dockerfile
  image: caddy:2.8.4-alpine
  container_name: caddy
  restart: unless-stopped
  user: ${UID}:${GID}
  networks:
    - docker_net0
  ports:
    - "80:80"
    - "443:443"
    - "443:443/udp"
  volumes:
    - ${HOME}/data/caddy/Caddyfile:/etc/caddy/Caddyfile
    - ${HOME}/data/caddy/sites:/etc/caddy/sites  # 存放配置文件
    - ${HOME}/data/caddy/srv:/srv  # 存放静态资源
    - ${HOME}/data/caddy/data:/data
    - ${HOME}/data/caddy/config:/config

networks:
  # 自定义一个桥接网络
  docker_net0:

构建并启动

echo -e "UID=$(id -u)\nGID=$(id -g)" > .env
docker compose up --build -d caddy
