PowerShell7本地代理配置

约 381 字大约 1 分钟

powershell

2025-01-18

简介

在开启系统代理后PowerShell并不会走代理，需要手动设置ALL_PROXY HTTP_PROXY HTTPS_PROXY，每开一个PowerShell都需要手动配置一下，很是繁琐。想了一下可以在启动PowerShell之前可以先读取系统代理设置，判断是否开启系统代理来自动设置环境变量让流量走代理。

$PROFILE配置文件

在 PowerShell 中，$PROFILE 是一个自动变量，表示当前用户的 PowerShell 配置文件的路径。这个配置文件是一个脚本文件（通常是 .ps1 文件），PowerShell 在启动时会自动加载并执行其中的命令。通过编辑 $PROFILE 文件，你可以自定义 PowerShell 的行为，例如设置别名、定义函数、初始化环境变量等。

编辑$PROFILE 文件

function Set-ProxyFromSystem {
  # 获取系统代理设置
  $proxySettings = Get-ItemProperty -Path "HKCU:\Software\Microsoft\Windows\CurrentVersion\Internet Settings"
  $proxyEnabled = $proxySettings.ProxyEnable
  if ($proxyEnabled) {
    # 解析代理 IP 和端口
    $proxyIP, $proxyPort = $proxySettings.ProxyServer -split ":"

    # 设置环境变量
    $Env:ALL_PROXY = "socks://$proxyIP`:$proxyPort"
    $Env:HTTP_PROXY = "http://$proxyIP`:$proxyPort"
    $Env:HTTPS_PROXY = "http://$proxyIP`:$proxyPort"

    Write-Host "检测到系统代理已开启"
    Write-Host "ALL_PROXY=$Env:ALL_PROXY"
    Write-Host "HTTP_PROXY=$Env:HTTP_PROXY"
    Write-Host "HTTPS_PROXY=$Env:HTTPS_PROXY"
  }
}

# 调用函数
Set-ProxyFromSystem

## Clear proxy
function Clear-Proxy {
  $Env:ALL_PROXY = $null
  $Env:HTTP_PROXY = $null
  $Env:HTTPS_PROXY = $null
  Write-Host "Proxy cleared (ALL_PROXY HTTP_PROXY HTTPS_PROXY is now empty)."
}

## Set alias
Set-Alias -Name unproxy -Value Clear-Proxy
