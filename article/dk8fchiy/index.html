ollama部署deepseek r1模型并使用open-webui访问

约 584 字大约 2 分钟

dockeraiollamadeepseek

2025-02-08

注意

以下操作都在Ubuntu环境下进行，也可在其他Linux系统下操作，但如果出现问题请自行解决。

安装ollama并下载deepseek r1大模型

  1. 安装ollama
curl -fsSL https://ollama.com/install.sh | sh
  1. 下载deepseek r1大模型（根据自己电脑硬件选择合适的参数，我使用的是默认7b参数）
ollama run deepseek-r1:7b

提示

等待下载完成后就可以直接在终端进行对话了，可使用/?命令查看帮助，退出当前对话使用/bye

  1. 修改ollama.service配置
sudo vim /etc/systemd/system/ollama.service

# 新增Environment环境变量OLLAMA_HOST=0.0.0.0
  1. 重启ollama.service服务
sudo systemctl daemon-reload

sudo systemctl restart ollama

使用Docker安装open-webui

提示

安装open-webui后可通过网页端访问大模型

  1. 安装NVIDIA Container Toolkit
curl -fsSL https://nvidia.github.io/libnvidia-container/gpgkey | sudo gpg --dearmor -o /usr/share/keyrings/nvidia-container-toolkit-keyring.gpg \
  && curl -s -L https://nvidia.github.io/libnvidia-container/stable/deb/nvidia-container-toolkit.list | \
    sed 's#deb https://#deb [signed-by=/usr/share/keyrings/nvidia-container-toolkit-keyring.gpg] https://#g' | \
    sudo tee /etc/apt/sources.list.d/nvidia-container-toolkit.list

sudo -E apt-get update

sudo apt-get install -y nvidia-container-toolkit
  1. 新增compose.yaml配置

注意

不要使用non-root用户启动，会出现访问权限问题

services:
  openwebui:
    image: ghcr.io/open-webui/open-webui:cuda
    container_name: open-webui
    networks:
      - bridge_net0
    restart: always
    ports:
      - 3000:8080
    volumes:
      - open-webui:/app/backend/data
    environment:
      - NVIDIA_VISIBLE_DEVICES=all
    extra_hosts:
      # 容器访问宿主机
      - host.docker.internal:host-gateway
    deploy:
      resources:
        reservations:
          devices:
            - driver: nvidia
              count: all
              capabilities: [gpu]

networks:
  bridge_net0:
    driver: bridge
  
volumes:
  open-webui:
  1. 创建并启动open-webui容器
docker compose up --build -d openwebui
  1. 浏览器访问http://localhost:3000进行初始化设置

注意

首次创建管理员并登录后会出现空白，等待一段时间即可，网页出现内容后在设置中关闭外部连接 -> OpenAI API选项

可选 - 使用coredns+caddy设置局域网自定义域名和反向代理访问

参考这篇文章安装coredns

Corefile配置文件新增IP -> 域名映射

.:53 {
    bind 0.0.0.0
    hosts {
            # ip your.domain
            fallthrough
    }
    forward . 8.8.8.8
    cache 120
    reload 6s
    log
    errors
}
参考这篇文章安装caddy

Caddyfile配置文件新增反向代理配置

your.domain:80 {
  encode zstd gzip
  reverse_proxy openwebui:8080 # 注意openwebui容器要和caddy容器在同一个桥接网络下
}

更多内容请查阅ollama｜open-webui文档
