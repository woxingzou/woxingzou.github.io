局域网使用coredns作为DNS服务器解析自定义域名

约 617 字大约 2 分钟

网络corednsdockercaddy

2025-02-06

注意

以下操作都在Ubuntu环境下进行，也可在其他Linux系统下操作，但如果出现问题请自行解决。

使用Docker安装coredns

  • Data
    • coredns
      • Corefile
  • Docker
    • coredns

      • Dockerfile

  1. 创建Dockerfile文件
FROM coredns/coredns:latest
  1. 创建Corefile文件
.:53 {
    bind 0.0.0.0
    hosts {
            # 注意你的局域网网段
            192.168.0.88 your.domain # 自定义的局域网ip和域名
            fallthrough
    }
    forward . 8.8.8.8 # dns上游
    cache 120
    reload 6s
    log
    errors
}
  1. 创建compose.yaml文件
services:
  coredns:
    build: 
      context: coredns
      dockerfile: Dockerfile
    image: coredns:latest
    container_name: coredns
    restart: always
    user: ${UID}:${GID}
    networks:
      - bridge_net0
    ports:
      - 53:53/tcp
      - 53:53/udp
    # 指定配置文件启动
    command: ["-conf", "/etc/coredns/Corefile"]
    volumes:
      - ${DATA_DIR}/coredns/Corefile:/etc/coredns/Corefile

networks:
  bridge_net0:
  1. 创建install.sh安装脚本
#!/bin/bash -xe

DATA_DIR=$HOME/Data
DOCKER_DIR=$HOME/Docker

COREDNS_DIR=$DATA_DIR/coredns

echo -e "DATA_DIR=$DATA_DIR\nUID=$(id -u)\nGID=$(id -g)" > $DOCKER_DIR/.env

# 创建coredns目录结构
setup_coredns() {
  if [ -d $COREDNS_DIR ]; then
    rm -rf $COREDNS_DIR
  fi
  mkdir -p $COREDNS_DIR
  cp -r $DOCKER_DIR/coredns/Corefile $COREDNS_DIR
}

# 根据参数执行相应的操作
for arg in "$@"; do
  case $arg in
    coredns)
      setup_coredns
      ;;
    *)
      echo "未知参数: $arg"
      ;;
  esac
done

if [ $# -eq 0 ]; then
  setup_coredns
fi
  1. 安装与启动
bash install.sh coredns
docker compose up --build -d coredns

注意

上述命令执行时需在Docker目录下

提示

如果启动coredns时提示53端口被占用

# 关闭 systemd-resolved 服务
sudo service systemd-resolved stop
# 编辑 systemd-resolved 的配置文件，修改DNS=8.8.8.8和DNSStubListener=no配置
sudo vim /etc/systemd/resolved.conf
# 保存后重启 systemd-resolved 服务
sudo service systemd-resolved restart
# 重新创建 /etc/resolv.conf 的符号链接
sudo rm /etc/resolv.conf
sudo ln -s /run/systemd/resolve/resolv.conf /etc/resolv.conf

客户端修改网络DNS配置

一般修改DNS配置需要设置静态IP，你可以参考这篇文章进行静态IP的设置，DNS服务器IPv4地址填写你部署coredns的服务器IP。 比如我的路由器IP为192.168.0.1，部署coredns服务器的IP为192.168.0.66，某客户端(可以是其他电脑或者手机)IP为192.168.0.88那DNS配置的IPv4就是192.168.0.66。

验证配置

客户端终端执行nslookup your.domain 返回结果如下

Server:		192.168.0.66
Address:	192.168.0.66#53

Name:	your.domain
Address: 192.168.0.88

可选（使用caddy验证）

参考这篇文章安装caddy，Corefile添加IP -> 域名映射，Caddyfile新增配置

your.domain:80 {
  respond "Hello, world!"
}

浏览器访问http://your.domain，网页展示Hello, world!即为成功
